# NEON BREAK：星核突圍 — 完整遊戲企劃

版本：1.0 · 2026-10-14 · 狀態：待製作的設計方案

本文件定義下一版遊戲的完整體驗、內容規格和製作順序。現有版本是三關的打磚塊原型，已有鍵盤、滑鼠、觸控操作，以及寶石磚塊、擋板、球、背景和擊碎特效素材。下述章節、Boss、技能與存檔系統都屬於新增規劃。

## 1. 產品定位

**一句話介紹：駕駛反射艦，用球的反彈角度破解機關、拆解敵方核心，逐站奪回失控的太空設施。**

| 項目 | 設計 |
|---|---|
| 類型 | 街機打磚塊、機關解謎、關卡挑戰 |
| 遊玩平台 | 電腦與手機瀏覽器，GitHub Pages 靜態網站 |
| 主要玩家 | 喜歡短時間遊戲、視覺回饋與技巧挑戰的玩家 |
| 單關時間目標 | 2–4 分鐘；Boss 3–5 分鐘，需實測調整 |
| 一次遊玩 | 完成 2–4 關，約 10–15 分鐘 |
| 完整內容 | 5 章、30 關、5 隻 Boss；另有無盡與挑戰模式 |
| 商業規則 | 免費、無廣告、無抽卡、無付費能力 |
| 核心樂趣 | 瞄準、反彈、連鎖破壞、道具組合與破解機關 |

三個設計重點：

1. **每次接球都能做選擇。** 擋板接觸位置決定出球角度；玩家能主動瞄準弱點。
2. **每關都有辨識度。** 關卡差異來自目標與機關，而不只是球更快、磚更多。
3. **失敗後願意再玩。** 重試迅速、進度保留，畫面清楚告訴玩家失敗原因。

故事採短篇任務形式：中央 AI「監察者」封鎖了五座太空設施，玩家駕駛反射艦釋放星核。每章開始和結束最多各兩段對話，可跳過；背景與 Boss 表現負責大部分敘事。

## 2. 遊戲循環與通關規則

### 長期循環

選章節與關卡 → 查看任務、配置技能 → 發球、瞄準與接球 → 取得道具並完成目標 → 結算星等、取得研究點 → 解鎖新關與技能 → 挑戰更好的成績。

### 單關循環

觀察磚塊與弱點 → 在擋板上選擇發球位置 → 打出可控反彈 → 判斷道具值不值得追 → 使用技能處理危險 → 完成任務。

- 每關開始有 **3 次生命**，不把生命跨關累積。每次重試恢復 3 次。
- 多球狀態下，只有所有球都掉出場外才扣一次生命。
- 掉球後保留本關已破壞的磚塊；死亡重試則還原整關。
- 扣命會清除多球與暫時性道具，球回到擋板，玩家自行重新發球。
- 主線關卡預設無倒數死亡；計時只影響星等。限時挑戰另有清楚標示。
- 下一關以完成上一關解鎖；星等用於額外挑戰與外觀，不能卡住主線。
- 關卡最後剩餘少量磚塊時提供位置提示；30 秒無有效命中，顯示可啟用的一次瞄準協助。
- 所有必要目標都必須有普通球可完成的路徑；技能、稀有道具和永久升級不能成為通關前提。

## 3. 操作與反彈手感

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動擋板 | 滑鼠、← →、A / D | 遊戲區拖曳，手指可放在擋板下方 |
| 發球／釋放黏球 | 空白鍵或發球按鈕 | 專用發球按鈕 |
| 主動技能 | E 或技能按鈕 | 遊戲區外的技能按鈕 |
| 暫停 | Esc、P 或暫停按鈕 | 暫停按鈕 |
| 重試 | 暫停選單中的重試 | 暫停選單中的重試 |

空白鍵固定用於發球／釋球，暫停使用 P／Esc，避免一個按鍵在不同情境誤觸。

反彈規則：

- 擋板中心使球較垂直；兩端可打出最多約 60 度的斜角。
- 球的垂直速度設下限，避免長時間水平往返。
- 初始速度建議 320 邏輯像素／秒，主線通常控制在 320–480；加速道具效果也受上限約束。
- 主線速度提升以換關為主，不在一次接球後突然跳速。
- 接球輔助可擴大有效擋板寬度 15%，但球的顯示尺寸不變；結算標示輔助模式。
- 手機可選滑動跟隨或相對拖曳，不要求玩家手指直接覆蓋球和擋板。
- 視覺碰撞點要對應實際碰撞範圍；特效發光範圍不能算傷害範圍。
- 球碰撞採固定步進或掃掠判定，避免高速度穿磚；不同螢幕刷新率不得改變難度。

## 4. 磚塊與場景機關

| 類型 | 規則與辨識 | 戰術用途 |
|---|---|---|
| 寶石磚 | 1 次命中破壞，六色皆同耐久 | 建立基本打擊回饋 |
| 裝甲磚 | 2／3 次命中；裂痕及鉚釘表示耐久 | 改變清理順序 |
| 爆裂磚 | 破壞後傷害周圍八格各 1 點；有引信圖示 | 設計連鎖反應 |
| 能量磚 | 破壞後額外增加 10 點技能能量 | 鼓勵瞄準特定區域 |
| 補給磚 | 保證掉落預先配置的道具；有箱子圖示 | 提供可預期的戰術選擇 |
| 鑰匙磚 | 擊破後解除配對的鎖定障壁 | 建立簡單解謎順序 |
| 護盾磚 | 護盾期間彈球；護盾每 4 秒關閉 2 秒 | 測試時機，不能永久封死 |
| 移動磚 | 在標記軌道中往返，不侵入擋板安全區 | 增加瞄準變化 |
| 修復節點 | 每 6 秒修復附近一塊裝甲磚 1 點；節點本身 2 點耐久 | 先拆節點再清場 |
| 核心磚 | 任務目標，醒目輪廓、4 點耐久 | 讓勝利目標清楚可見 |
| 金屬障壁 | 不可破壞；深色與警示條紋 | 改變球路，不列入清場數量 |
| 相位磚 | 開關狀態決定實體／穿透；狀態有圖示與輪廓區別 | 建立後期機關組合 |

場景機關：

- **傳送門：** 成對出現，球出門後保留速度；有短暫再入冷卻，避免卡在門口循環。
- **偏轉場：** 局部、輕微改變球路，以箭頭動畫預告方向。
- **能量開關：** 命中切換障壁或相位磚；不可把唯一目標永久關在無法再接近的位置。
- **警戒光束：** 先標示路徑至少 1.2 秒，再生效；主線先用作球路障礙，Boss 戰才加入擋板危險。
- **可移動反射器：** 按固定節奏轉向，方向全程可見。

同一關通常最多兩種主要機關。新機關先單獨教學，再與既有規則組合。單關不靠大量同時出現的規則製造混亂。

## 5. 道具與組合

普通磚的初始掉落機率建議 12%；場上最多兩個未接道具，取得後再開下一次掉落。補給磚不受隨機機率限制。主線重要道具放在固定補給磚，避免玩家因運氣無法完成任務。

| 道具 | 起始參數 | 疊加與限制 |
|---|---|---|
| 加長擋板 | 寬度 +35%，15 秒 | 重複取得刷新時間，不無限加長 |
| 三重球 | 分出兩顆球 | 場上最多 5 球；取得同類時補到上限 |
| 黏附擋板 | 接住球，10 秒 | 手動釋放；到期後有 1 秒提示再自動發球 |
| 穿透球 | 6 秒，對可破壞磚每次接觸造成 1 點傷害 | 同一塊磚在同一穿越過程只受一次傷害 |
| 雷射擋板 | 每秒一次雙彈，8 秒 | 不需要連點；只傷害可破壞目標 |
| 緩速 | 球速降為 75%，10 秒 | 到期在 1 秒內平滑恢復 |
| 底部護罩 | 接住一次原本會掉落的球 | 多球時每顆觸發分別消耗；最多儲存 2 次 |
| 星核補給 | 取得 100 分及 15 點能量 | 不額外增加生命 |

道具的圖示、輪廓與名稱都要能辨認，不能只用顏色區分。HUD 顯示作用中道具與倒數，最後 3 秒給柔和提醒。

有趣組合包括「多球＋穿透」快速拆裝甲、「黏附＋加長」重新安排球路、「雷射＋爆裂磚」觸發連鎖。多球採最多 5 顆，是為了維持球路可讀性。

## 6. 主動技能與成長

玩家一局裝備一個技能，關卡中不能切換。技能能量為 0–100，普通磚破壞增加 4 點，Boss 有效命中增加 5 點；僅反彈到不受傷的障壁不增加能量。

| 技能 | 成本 | 效果 |
|---|---|---|
| 緊急護盾 | 50 | 3 秒內第一次掉球由底部彈回，不扣生命 |
| 瞄準捕捉 | 45 | 6 秒內下一次擋板接球會黏住球，可重新選發球角度 |
| 星核脈衝 | 70 | 對上半場可破壞磚各造成 1 點傷害；不跨過關閉的 Boss 護盾 |

技能需透過第 3、9、15 關的首次通關依序解鎖。每個 Boss 都要能不用技能通關，技能只是提高操作容錯。

研究點規則：

- 每關首次通關 2 點；首次取得二星、三星各再給 1 點，重玩不重複領取。
- 前 10 關可取得 40 點，完整 30 關可取得 120 點，玩家能事先知道取得上限。
- 三條升級線各三階，每階成本依序為 4、8、12，共需 72 點完成三線。
- 升級線分別為初始能量 +10／20／30、道具持續時間 +5／10／15%、補給分數 +10／20／30%。
- 可免費重置研究點，避免早期選錯造成負擔。
- 升級不提高球的基本傷害、不增加永久生命；關卡平衡以未升級配置驗收。
- 三星與章節成就解鎖擋板外觀、球尾跡和背景配色，純外觀不改碰撞。

## 8. Boss 規格

Boss 的弱點有亮邊與閃動圖示；攻擊使用形狀、軌跡和聲音預告。危險路徑不得同時覆蓋整個可移動範圍。被攻擊的擋板會失去一條生命並進入重新發球狀態，不在同一輪連續扣命。

| Boss | 起始耐久 | 戰鬥流程 | 主要考驗 |
|---|---|---|---|
| 守門者 | 2 個鎖扣各 2 點，核心 8 點 | 拆鎖扣 → 核心完全暴露 | 左右瞄準 |
| 熔爐巨像 | 3 片裝甲各 3 點，核心 10 點 | 逐片破甲；週期性預告熱流 → 暴露核心 | 連鎖與接球位置 |
| 門站監督者 | 2 個側翼各 4 點，核心 12 點 | 球穿門擊側翼 → 核心暴露，傳送門位置固定 | 理解傳送與球路 |
| 稜鏡矩陣 | 4 個節點各 3 點，核心 12 點 | 每次至少一個節點開放 → 拆節點後核心開放 | 等待窗口與選角度 |
| 監察者 | 三階段各 8／10／12 點 | 裝甲 → 傳送側翼 → 核心；階段切換提供 3 秒安全時間 | 已學機制的組合 |

- 每個 Boss 第一次遇到時先展示弱點規則，攻擊頻率逐階段提高。
- 主線 Boss 不依賴玩家連點射擊，也不能只靠抽到特定道具獲勝。
- 高難度版增加攻擊節奏與弱點變化，與主線版本分開。
- 上述耐久是製作起始值；以首見玩家能在 3–5 分鐘理解並完成為調整目標。

## 9. 分數、星等與重玩模式

計分起始規則：

- 普通磚 10 分，裝甲磚 25 分，機關節點 40 分，核心磚 100 分；破壞時給分，重複受傷不給分。
- 3 秒內連續破壞延長連擊，倍率由 ×1 增至 ×3，每 5 塊提升 0.5，3 秒沒有破壞則重置。
- 爆炸連鎖和雷射破壞計入連擊；同一磚塊只能結算一次。
- 通關給剩餘生命 ×100 分；Boss 額外 500 分。

主線星等：

1. 一星：完成任務。
2. 二星：完成任務，且掉命最多一次。
3. 三星：未掉命，且達到該關設計的時間目標。

每關時間目標依人工通關和玩家測試訂定，不套用同一時間。星等以最佳表現儲存，最低一星即可推進主線。

其他模式：

- **無盡防線：** 第 6 關後解鎖，每波明確換場；速度有上限，後期難度靠佈局與機關組合。
- **精準挑戰：** 固定關卡、少量核心、無永久升級，練習指定球路。
- **每週挑戰：** 固定種子與道具順序，以 UTC 週一為切換時間，頁面顯示實際起訖日期；所有玩家配置相同。
- **Boss 重戰：** 已通關 Boss 可單獨重玩，適合練習與刷個人成績。

第一版榜單是本機個人紀錄，清楚標示「此裝置」。公開全球排行榜需要伺服器、帳號與分數驗證，另列後續開發，不能把可修改的瀏覽器分數當可信成績。

## 10. 畫面、資訊與使用流程

頁面流程：標題畫面 → 章節地圖 → 關卡詳情／技能配置 → 遊戲 → 結算 → 下一關或重試。

- 標題畫面提供「繼續冒險」「選擇關卡」「挑戰模式」「設定」。
- 章節地圖每章六個節點，顯示鎖定、已通關、星等與 Boss 標記。
- 關卡詳情顯示任務目標、新機關、個人紀錄和配置技能，不先顯示大量說明。
- 遊戲上方顯示生命、分數、關卡、任務進度；下方放技能能量與手機操作按鈕。
- Boss 耐久條放在遊戲區頂部，不遮住球的活動路徑。
- 結算依序呈現完成／失敗、星等、分數、新紀錄、首次獎勵與下一步。
- 暫停提供繼續、重試、設定、回到地圖；離開未完成關卡時提醒本關進度將重置。
- 設定提供音量、音樂開關、接球輔助、降低動畫、對比模式與操作方式。
- 教學只在首次遇到時顯示，可重看；提示期間球暫停。

手機版以直向介面為主，按鈕至少 44 CSS 像素，技能按鈕放在遊戲區外。遊戲區保留一致的邏輯比例，不能因螢幕變窄就把物理球速乘大。支援手機安全區、旋轉螢幕後維持暫停狀態。

## 11. 美術與音效企劃

延續目前的透明寶石與科幻金屬風格，製作完整點陣圖素材。背景保持低對比，球使用全場最清楚的輪廓。磚塊耐久、開關和任務標記同時有圖形辨識。

| 素材群 | 第一批需求 |
|---|---|
| 基礎磚塊 | 沿用六種寶石磚，補裝甲 3 階損傷、爆裂、能量與補給 |
| 機關 | 鑰匙、核心、節點、障壁、開關、護盾開／關狀態 |
| 玩家 | 擋板正常／黏附／雷射外觀；球正常／穿透狀態 |
| 道具圖示 | 8 種掉落圖示，HUD 另有小尺寸版本 |
| 環境 | 5 章背景與章節地圖節點；背景不得喧賓奪主 |
| Boss | 5 隻完整靜態圖與分離的弱點、裝甲、受擊狀態 |
| 特效 | 接球、破磚、爆炸、傳送、護盾、Boss 命中與核心崩解 |
| UI | 技能、生命、研究點、星等、章節徽章 |

動畫以小型 PNG 圖集為主，背景用壓縮 WebP。每個素材交付透明度、尺寸、中心點、碰撞用途及生成紀錄；角色與 Boss 大幅動作另設製作流程。場景貼圖與物件圖集分離，避免每關載入整個遊戲。

回饋設計：

- 寶石磚受擊：短促亮點、少量碎片、高音敲擊。
- 裝甲受擊：裂痕變化與較低的金屬音。
- 擋板接球：輕微形變、位置對應的音高，不遮住球。
- 高連擊：音階逐步上升，倍率文字出現在 HUD，不追著球飛。
- Boss 階段轉換：背景配色微變、短音樂段落與清楚弱點提示。
- 音樂分為選單、各章、Boss 與結算；首個使用者操作後才啟用音訊。
- 音量記憶、可全靜音；失去視窗焦點時遊戲與音訊一起暫停。

降低動畫模式關閉震動、全場閃光和長尾跡，保留必要的攻擊預告與狀態辨識。

## 12. 平衡與內容驗收

本企劃的速度、掉落率、耐久和時間都是初始調整值，正式平衡需要試玩。

| 驗收項目 | 要求 |
|---|---|
| 首次遊玩 | 30 秒內理解移動與發球，第一關只教核心操作 |
| 教學節奏 | 每次新增最多一個主要規則，之後再組合 |
| 關卡可解 | 未升級、無隨機道具仍可通關，必要目標始終可接近 |
| Boss 預告 | 至少 1.2 秒預告，有可達的安全區，不同機關不連鎖必死 |
| 球路 | 不穿磚、不長時間卡住、不從關閉護盾獲取重複獎勵 |
| 多球 | 球數上限有效，所有球掉落才扣命，換關不留下舊球 |
| 失敗處理 | 能指出掉球／危險命中原因，兩次操作內可重試 |
| 存檔 | 重開瀏覽器保留通關紀錄，損壞存檔能安全恢復 |
| 可讀性 | 背景與特效不遮球，耐久與狀態不依賴單一顏色 |
| 手機操作 | 手指不必遮球，按鈕不與遊戲拖曳衝突 |
| 效能 | 指定測試手機與電腦後實測；目標 60 FPS，繁忙場面不持續低於 45 |

試玩重點依序為操作是否可控、規則是否容易理解、關卡是否有樂趣，再調整數字。可以觀察死亡位置、平均通關時間、重試率與技能使用次數，但第一版以本機除錯資料為主，不默默上傳玩家資料。

## 13. 製作架構與存檔

這是支援企劃落地的實作規格，不在遊戲介面向玩家展示。

- 由目前單一 HTML 拆成遊戲狀態、物理、關卡、道具、Boss、圖片／音訊資源、UI 與存檔模組。
- 狀態定義為：載入、主選單、地圖、關卡準備、遊玩、暫停、結算、錯誤。每次轉換清楚管理輸入、計時器和音訊。
- 關卡以 JSON 定義：章節、目標、必要磚塊、位置、耐久、機關、固定補給、掉落種子、星等時間。
- Boss 以狀態機管理階段、開盾窗口、攻擊預告與冷卻，不能讓動畫決定碰撞。
- 用 localStorage 保存版本號、已通關關卡、最高星等、最高分、研究點領取狀態、升級與設定。
- 存檔載入驗證資料範圍；新增版本有遷移策略。首次獎勵記錄與研究點更新須一起寫入，避免重複領取。
- 可匯出／匯入 JSON 備份，清楚說明只保存遊戲紀錄；尚未支援跨裝置自動同步。
- 主線只在完成關卡後存檔；頁面重開從該關準備畫面開始。
- 初始只載入 UI 與第一章資源，進入下一章才載入對應素材；預載下一關，圖片錯誤可重試。
- 暫停與背景分頁不得推進物理、道具倒數、Boss 攻擊或計時。

## 14. 開發順序與交付

先完成可玩的第一章，再擴充全內容。每階段都有能直接檢查的交付物，不以功能數量代替完成度。

| 階段 | 交付內容 | 完成門檻 |
|---|---|---|
| A：遊戲基礎 | 狀態管理、可控角度、暫停、載入、章節選單、存檔 | 完整走過進入、開始、失敗、重試與結算 |
| B：第一章成品 | 6 關、守門者、4 種道具、護盾技能、音效與結算 | 可從第一關連續玩到第一章 Boss，手機與電腦可操作 |
| C：戰術擴充 | 第二／三章、裝甲與爆裂機制、補全 8 道具、3 技能、研究點 | 規則互動明確，獎勵不重複領取 |
| D：主線完整 | 第四／五章、30 關、5 Boss、故事與結局、完整素材 | 全流程無卡關、必要目標可解、低配置可通關 |
| E：重玩與打磨 | 無盡、精準、每週挑戰、Boss 重戰、外觀、輔助設定 | 平衡試玩、存檔遷移、效能與手機回歸檢查完成 |

第一章的四種道具是加長、三重球、緩速、底部護罩。第二章再加入黏附與雷射，第三章加入穿透與星核補給；這樣玩家有學習順序，美術與程式也能逐批驗收。

製作優先順序：

1. 核心手感、圖片可讀性、失敗／重試流程。
2. 第一章六關與首隻 Boss，建立完整的遊戲前後流程。
3. 章節內容、規則組合、進度與研究點。
4. 更多模式、外觀與高級特效。

後續版本才考慮線上排行榜、帳號同步、自訂關卡編輯器、分享關卡碼與雙人合作；這些功能會增加後端、驗證或網路同步需求，不列入第一版完成條件。
